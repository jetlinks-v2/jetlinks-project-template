# 上游来源

此目录仅引入 SaaS 运行时扩展源码，不包含 SaaS 前端聚合工程的配置或其他业务模块。

- 仓库：https://github.com/jetlinks-v2/saas-runtime-ui
- 分支：`2.20`
- 来源提交：`3aeef596a9f987fb05a7dd876a4297257f3ed33e`
- 上游目录：`modules/saas-runtime-ui/`

该目录在上游是普通源码目录，因此由当前脚手架直接管理；前端壳及标准 UI 使用 `runtime-ui/` 下已有的独立源码目录。此扩展直接引用认证与设备 UI；脚手架另按需装配规则引擎和边缘网关。更新时以该目录的发布提交同步，核对其跨模块依赖并集中验证，不复制上游聚合工程的其他模块或个人环境配置。当前工作区的安装、启动方式见 `runtime-ui/独立启动说明.md`。
