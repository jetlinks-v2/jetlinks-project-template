# JetLinks 国际化规范 - AI 辅助指南

## 概述

JetLinks 使用标准的 Java Properties 文件进行国际化配置，支持中文(messages_zh.properties)和英文(messages_en.properties)。

**⚠️ 重要原则**：
1. **必须配置**：枚举国际化、实体类字段国际化、功能权限国际化
2. **无需配置**：数据校验消息、通用CRUD操作（query、save、delete等）
3. **按需配置**：仅当使用 `@ResourceAction(id="xxx")` 自定义操作时才需要配置对应的action国际化

## 文件位置

国际化文件应放在模块的资源目录下：

```
src/main/resources/i18n/{模块名}/
├── messages_zh.properties  (中文)
└── messages_en.properties  (英文)
```

**示例**：
- `device-manager` 模块: `src/main/resources/i18n/device-manager/messages_zh.properties`
- `authentication-manager` 模块: `src/main/resources/i18n/authentication-manager/messages_zh.properties`

## 核心规范

### 1. 枚举类国际化

**格式规范**：`完整包名.枚举类名.枚举值=显示文本`

**规则说明**：
- 使用完整的包名路径
- 包名 + 枚举类名 + 枚举值，用点(.)连接
- 枚举值要与代码中定义的枚举值名称完全一致（区分大小写）

**示例 1 - 设备状态枚举**：

```java
// Java 枚举定义
package org.jetlinks.pro.device.enums;

public enum DeviceState {
    notActive,  // 未激活
    offline,    // 离线
    online      // 在线
}
```

```properties
# messages_zh.properties
org.jetlinks.pro.device.enums.DeviceState.notActive=未激活
org.jetlinks.pro.device.enums.DeviceState.offline=离线
org.jetlinks.pro.device.enums.DeviceState.online=在线
```

```properties
# messages_en.properties
org.jetlinks.pro.device.enums.DeviceState.notActive=Not Active
org.jetlinks.pro.device.enums.DeviceState.offline=Offline
org.jetlinks.pro.device.enums.DeviceState.online=Online
```

**示例 2 - 设备类型枚举**：

```java
// Java 枚举定义
package org.jetlinks.pro.device.enums;

public enum DeviceType {
    device,          // 直连设备
    childrenDevice,  // 网关子设备
    gateway          // 网关设备
}
```

```properties

org.jetlinks.pro.device.enums.DeviceType.childrenDevice=网关子设备
org.jetlinks.pro.device.enums.DeviceType.gateway=网关设备
```

**示例 3 - 任务状态枚举**：


### 3. 功能权限国际化（必须配置）

**格式规范**：`hswebframework.web.system.permission.{权限ID}=权限名称`

**规则说明**：
- 固定前缀：`hswebframework.web.system.permission.`
- 权限ID：对应 Controller 上 `@Resource(id = "xxx")` 注解中的 id 值
- 用于功能模块、菜单等权限控制的显示名称

**Java 代码示例**：

```java
@RestController
@RequestMapping("/device/product")
@Resource(id = "device-product", name = "设备产品")  // 这里的 id
@Tag(name = "设备产品管理")
public class DeviceProductController {
    // ...
```

```properties
# messages_zh.properties
hswebframework.web.system.permission.device-product=设备产品
```

### 4. 自定义操作国际化（按需配置）

**⚠️ 重要说明**：
- **通用CRUD操作无需配置**：query、save、add、update、delete、import、export 等标准操作已由系统全局定义，无需在模块中重复配置
- **仅在使用自定义操作时配置**：只有当在 Controller 中使用 `@ResourceAction(id="custom-action")` 定义自定义操作时，才需要配置对应的国际化

**格式规范**：`hswebframework.web.system.action.{操作ID}=操作名称`

**规则说明**：
- 固定前缀：`hswebframework.web.system.action.`
- 操作ID：对应 `@ResourceAction(id = "xxx")` 注解中的 id 值
- 用于自定义操作按钮的显示名称

**自定义操作示例**：

```java
// Java Controller 代码 - 自定义操作
@RestController
@RequestMapping("/device/instance")
@Resource(id = "device-instance", name = "设备实例")
public class DeviceInstanceController {
    
    // 自定义操作：激活设备
    @PostMapping("/{id}/_active")
    @ResourceAction(id = "active", name = "激活设备")  // 自定义操作
    public Mono<Void> activeDevice(@PathVariable String id) {
        // ...
    }
    
    // 自定义操作：重置设备
    @PostMapping("/{id}/_reset")
    @ResourceAction(id = "reset", name = "重置设备")  // 自定义操作
    public Mono<Void> resetDevice(@PathVariable String id) {
        // ...
    }
}
```

**对应国际化配置**：

```properties
# messages_zh.properties
# 仅需配置自定义操作
hswebframework.web.system.action.active=激活设备
hswebframework.web.system.action.reset=重置设备

# ❌ 无需配置通用CRUD操作（系统已全局定义）
# hswebframework.web.system.action.query=查询
# hswebframework.web.system.action.save=保存
# hswebframework.web.system.action.delete=删除
```

```properties
# messages_en.properties
hswebframework.web.system.action.active=Active Device
hswebframework.web.system.action.reset=Reset Device
```

## AI 代码生成规范

### 生成枚举类时的国际化（必须）

当生成枚举类时，**必须**同步生成国际化配置：

```java
// 1. 生成枚举类
package org.jetlinks.pro.yourmodule.enums;

public enum YourEnum {
    value1,  // 值1
    value2,  // 值2
    value3   // 值3
}
```

```properties
# 2. 必须在 messages_zh.properties 中添加
org.jetlinks.pro.yourmodule.enums.YourEnum.value1=值1
org.jetlinks.pro.yourmodule.enums.YourEnum.value2=值2
org.jetlinks.pro.yourmodule.enums.YourEnum.value3=值3
```

### 生成实体类时的国际化（必须）

当生成实体类时，**必须**为所有业务字段添加国际化配置：

```java
// 1. 生成实体类
package org.jetlinks.pro.yourmodule.entity;

public class YourEntity extends GenericEntity<String> {
    private String name;        // 名称
    private String description; // 描述
    private String status;      // 状态
}
```

```properties
# 2. 必须在 messages_zh.properties 中添加
org.jetlinks.pro.yourmodule.entity.YourEntity.id=ID
org.jetlinks.pro.yourmodule.entity.YourEntity.name=名称
org.jetlinks.pro.yourmodule.entity.YourEntity.description=描述
org.jetlinks.pro.yourmodule.entity.YourEntity.status=状态
```

### 生成Controller时的国际化（功能权限必须，自定义操作按需）

```java
// Controller 代码
@RestController
@RequestMapping("/your/path")
@Resource(id = "your-resource", name = "资源名称")  // 功能权限ID
public class YourController {
    
    // 标准CRUD方法无需配置国际化
    
    // 自定义操作需要配置国际化
    @PostMapping("/{id}/_custom")
    @ResourceAction(id = "custom-action", name = "自定义操作")
    public Mono<Void> customAction(@PathVariable String id) {
        // ...
    }
}
```

```properties
# messages_zh.properties
# 功能权限（必须配置）
hswebframework.web.system.permission.your-resource=资源名称

# 自定义操作（仅在使用@ResourceAction时配置）
hswebframework.web.system.action.custom-action=自定义操作

# ❌ 标准CRUD操作无需配置
# hswebframework.web.system.action.query=查询
# hswebframework.web.system.action.save=保存
```

## 注意事项

### ✅ 正确示例

```properties
# 1. 完整包名
org.jetlinks.pro.device.enums.DeviceState.online=在线

# 2. 枚举值完全匹配
org.jetlinks.pro.device.enums.TaskState.sendError=发送失败

# 3. 驼峰命名保持一致
org.jetlinks.pro.device.entity.DeviceInstanceEntity.productName=产品名称
```

### ❌ 错误示例

```properties
# 1. 缺少完整包名（错误）
DeviceState.online=在线

# 2. 枚举值不匹配（错误：代码中是 sendError，不是 send_error）
org.jetlinks.pro.device.enums.TaskState.send_error=发送失败

# 3. 字段名不匹配（错误：代码中是 productName，不是 product_name）
org.jetlinks.pro.device.entity.DeviceInstanceEntity.product_name=产品名称

# 4. 包名错误（错误：多了 .enums.DeviceState）
org.jetlinks.pro.device.enums.DeviceState.DeviceState.online=在线
```

## 检查清单

创建国际化配置时，请确认：

**必须配置**：
- [ ] 国际化文件放在正确的目录 `src/main/resources/i18n/{模块名}/`
- [ ] 同时创建了中文和英文版本
- [ ] 枚举值使用完整包名：`包名.枚举类名.枚举值`
- [ ] 实体字段使用完整包名：`包名.实体类名.字段名`
- [ ] 枚举值/字段名与代码中定义完全一致
- [ ] 功能权限已配置：`hswebframework.web.system.permission.{权限ID}`
- [ ] 文件使用 UTF-8 编码或 Unicode 转义
- [ ] 中英文内容对应一致

**无需配置**：
- [x] ~~通用CRUD操作（query、save、delete等）~~ 系统已全局定义
- [x] ~~数据校验消息~~ 系统自动处理
- [x] ~~通用提示消息~~ 系统自动处理

**按需配置**：
- [ ] 自定义操作：仅当使用 `@ResourceAction(id="xxx")` 时需要配置
